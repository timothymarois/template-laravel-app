# Laravel Primevue Template

### Tech Stack

- Laravel 11
- Vue 3
- Tailwind 3
- PrimeVue 3 (Unstyled, with tailwind-lara presets)

### Docker:

The docker set up is used for your local env and tests.

You can run in docker desktop app or `./vendor/bin/sail up`.

- PHP 8.3
- MySQL 8
- Redis


## Setup

Install client-side:

```bash
npm install
```

Install server-side:

```bash
composer install
```

## Build

For local testing:

```bash
npm run dev
```

```bash
npm run build
```
