# Laravel App Template

This is a starter kit for any project and it can be used as a quick playground to get you from 0 to 100 in 5 minutes.

## Setup

Install client-side:

```bash
npm install
```

Install server-side: (should do this through the docker container)

```bash
composer install
```

## Build

For local testing:

```bash
npm run dev
```

```bash
npm run build
```
