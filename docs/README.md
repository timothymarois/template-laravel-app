# template-laravel-app documentation

The documentation home. Two entry paths: **using the stack** starts with the brief; **working on it**
starts with the codemap, then the home your task lands in.

The rules every agent follows are in [`AGENTS.md`](../AGENTS.md) at the repository root, not here — it
carries the conventions and the worked ✅/❌ code galleries for this stack.

> **Just forked this template?** `BRIEF.md` and `CODEMAP.md` below describe *the template*. Rewrite
> `BRIEF.md` for your product and bring `CODEMAP.md` in line with your tree — the adoption prompt in
> [`.template/ADOPT.md`](../.template/ADOPT.md) walks through it. The `concepts/` and `guides/` pages
> describe the shared stack and stay true in a fork.
